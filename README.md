# 🌦️ Погода Беларуси (Belarus Weather)

Современное Android-приложение погоды для Республики Беларусь на базе **Jetpack Compose** и **Material Design 3**: с детальным радаром атмосферных явлений, прогнозом осадков по минутам, предупреждениями Белгидромета и МЧС, а также виджетом для рабочего стола.

---

## 🚀 Как скачать и запустить за 1 минуту (Без тремора и настроек)

### Вариант 1. Скачать готовый `.apk` прямо на телефон (Рекомендуется)

Вам не нужно устанавливать программы для разработки или компилировать код вручную. GitHub автоматически собирает установочный файл:

1. Откройте страницу репозитория на телефоне или компьютере.
2. Справа в блоке **Releases** нажмите на **[Releases / Готовый APK](../../releases)** (или вкладку **[Actions](../../actions)** -> последний запуск -> блок **Artifacts**).
3. Скачайте файл **`app-debug.apk`**.
4. Нажмите на скачанный файл на вашем Android-телефоне и выберите **«Установить»** *(если телефон спросит разрешение на установку из неизвестных источников — нажмите «Разрешить»)*.
5. Готово! Приложение установлено и готово к использованию.

---

### Вариант 2. Запуск через Android Studio (для разработчиков)

Если вы хотите запустить проект в среде разработки:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```
2. Откройте **Android Studio** -> нажмите **Open** -> выберите папку проекта.
3. Дождитесь автоматической загрузки зависимостей Gradle Wrapper.
4. Подключите телефон по USB или запустите виртуальный эмулятор Android.
5. Нажмите зелёную кнопку **Run ▶** (или сочетание клавиш `Shift + F10`).
   Приложение сразу соберется и запустится на вашем устройстве!

---

### Вариант 3. Сборка APK через терминал в одну команду

Если у вас установлена Java (JDK 17 или новее):

- **Windows:**
  ```cmd
  gradlew.bat assembleDebug
  ```
- **macOS / Linux:**
  ```bash
  ./gradlew assembleDebug
  ```

Готовый файл для установки появится по пути:
`app/build/outputs/apk/debug/app-debug.apk`.

## 🌟 Основные возможности

- 🇧🇾 **Специально для Беларуси:** Полная база областных центров и малых городов (Минск, Брест, Гродно, Витебск, Могилёв, Гомель, Бобруйск, Барановичи, Пинск, Полоцк, Борисов, Мозырь, Солигорск и др.).
- ⏱️ **Поминутный таймлайн дождя:** Точный статус вида *"Дождь прекратится через ~35 минут"* и 15-минутная динамическая диаграмма интенсивности осадков.
- 📡 **Интерактивная карта циклонов и осадков:** Векторная карта Беларуси со слайдером времени от -30 минут до +120 минут вперед и анимацией движения облачности.
- ⚠️ **Предупреждения Белгидромет / МЧС:** Желтый, оранжевый и красный уровни опасности с практическими рекомендациями по безопасности.
- 📱 **Виджет для рабочего стола Android:** Быстрый просмотр погоды и статуса осадков без открытия приложения.
- 💾 **Автономный режим (Room DB):** Полное сохранение прогноза в локальной базе данных для работы без доступа к интернету.

---

## 🛠 Стек технологий

- **Язык:** Kotlin
- **Интерфейс:** Jetpack Compose (Material 3)
- **База данных:** Room (SQLite)
- **Сетевой клиент:** Retrofit + KotlinX Serialization
- **CI/CD:** GitHub Actions (автоматическая сборка APK и создание релизов)
